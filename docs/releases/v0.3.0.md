# Archi v0.3.0

Released 2026-10-06. This release adds package metrics, type-only import controls,
and comparison of architecture across Git commits.

## New features

- **Package-import instability:** inspect distinct incoming and outgoing packages,
  the ratio `outgoing / (incoming + outgoing)`, and every contributing import.
  Isolated packages show N/A. Metrics are informational, with explicit coverage
  exclusions and provisional values for incomplete analysis.
- **Type-only imports:** recognized `TYPE_CHECKING` guards and explicit `typing`
  aliases label individual import sites. A browser checkbox filters the map and
  metrics. `include-type-only = false` in `[tool.archi]` separately excludes those
  sites from cycle and forbidden-dependency rules. Default behavior includes all
  imports, and exports always retain all evidence.
- **Commit comparison:** `archi compare PATH --base REF --head REF` opens a change
  list with added/removed packages, modules and dependencies, changed diagnostics,
  and before/after evidence. Both snapshot maps are available. `--json` or `-o`
  exports deterministic comparison JSON. The checkout and index stay untouched.

## Compatibility and limitations

**Graph JSON is now schema 2.0.** Every evidence site requires a boolean
`type_only` field. Consumers that require schema 1.0 must be updated, and old
snapshots must be regenerated. The strict reader and browser reject schema 1.0.
Comparison has its own envelope version 1.0, embedding two schema-2.0 graphs.

Requires Python 3.11+; the installed explorer has no Python runtime dependencies
and needs no Node installation. Commit comparison additionally requires Git and
locally available commits. It does not fetch refs or analyze uncommitted changes.

Renames appear as removal plus addition. Line/text/site-count changes are separate
from structural dependency changes. Missing-side observations are uncertain when
analysis is incomplete. Each commit uses its own configuration. Submodules and
symlinks are omitted with visible issues. Interfaces/class signatures, metric
history/deltas, and rename inference are not implemented.

Type-only recognition is conservative: ambiguous, rebound, compound, negated, or
dynamic guards remain ordinary imports. This is static dependency analysis, not
a runtime execution graph. Existing `check`/`export` exit codes are unchanged;
comparison returns 0 when complete and 2 when incomplete or invalid.

## Install and try

Download the wheel attached to this GitHub release, then:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install ./archi_explorer-0.3.0-py3-none-any.whl
.venv/bin/archi --version
.venv/bin/archi /path/to/repository
.venv/bin/archi compare /path/to/repository --base HEAD~1 --head HEAD
```

Windows uses `.venv\Scripts\python.exe` and `.venv\Scripts\archi.exe`.
Linux is the validated platform; other operating systems are not certified here.
The release includes a wheel, source distribution, and SHA-256 checksums.
